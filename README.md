# NeuroTrainer

## Version
0.1

---

## Мета проєкту

Створити програму NeuroTrainer для роботи з EEG у реальному часі.

Перший пристрій:
- Muse 2

У майбутньому:
- Muse S
- OpenBCI
- Unicorn
- Інші LSL-пристрої

---

## Основні можливості

- Підключення до EEG
- Онлайн аналіз сигналу
- FFT
- PSD (Welch)
- Аналіз Delta / Theta / Alpha / Beta / Gamma
- Нейрофідбек
- Візуалізація
- Запис сесій
- AI-аналіз (у майбутньому)

---

## Структура

notebooks/   — експерименти

src/         — основний код

data/        — EEG записи

exports/     — результати

sounds/      — аудіо

docs/        — документація

models/      — AI моделі

tests/       — перевірка коду

assets/      — картинки та іконки
